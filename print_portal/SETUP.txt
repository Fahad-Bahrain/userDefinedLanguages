FIRST-TIME SETUP
----------------
1. Copy the print_portal\ folder into C:\AIX_Monitor\

2. Double-click  C:\AIX_Monitor\print_portal\run.bat
   - Python packages install automatically on first run
   - Oracle_printers.xlsx is found automatically in C:\AIX_Monitor\

3. Open browser: http://localhost:5000

NOTE: Oracle_printers.xlsx stays in C:\AIX_Monitor\ — no need to copy it.
      The app looks in its own folder first, then the parent folder.

NETWORK ACCESS FOR OTHER PCS (optional)
-----------------------------------------
- Open Windows Firewall for TCP port 5000 on this PC
- Other PCs on the network: http://<your-pc-ip>:5000

ADDING A NEW USER
-----------------
Edit users.json and add:
  "newuser": {
    "password": "NewUser@123",
    "name": "Display Name",
    "role": "user",
    "prefixes": ["XX_"]
  }
No restart needed — users.json is read on every login.

ADDING A NEW DIVISION / QUEUE PREFIX
--------------------------------------
Add new prefixes to the user's "prefixes" list in users.json.
Add new printers to Oracle_printers.xlsx (no restart needed).

ACTIONS EXPLAINED
-----------------
Check Queue   — Shows all current print jobs (lpstat -o <queue>)
Cancel All    — Cancels every job in the queue
Cancel Job    — Cancels one specific job by job ID
Ping          — Pings the printer IP from the AIX server
Enable        — Enables the queue (enable <queue>)
Disable       — Disables the queue (disable <queue>)
Print Test    — Sends /home/sample-print to the queue via lp -d
View Log      — Shows tail of queue spool log or qdaemon log

TROUBLESHOOTING
---------------
- "Oracle_printers.xlsx not found"  → confirm file exists in C:\AIX_Monitor\
- SSH timeout / connection errors   → check network path to ekkhp01a port 22
- "No printers assigned"            → check prefixes in users.json match queue names in Excel
- Port 5000 already in use          → change port number at bottom of app.py
